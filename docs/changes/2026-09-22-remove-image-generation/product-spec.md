# 产品规格：移除图片生成能力

## 变更状态

状态：已完成
完成日期：2026-09-22

## 背景与目标

Mint 当前定位为个人知识工作台。图片生成属于外围能力，与核心的 Wiki 采集、检索、引用问答和 Agent 工作流无关。本变更作为第一阶段功能收敛点，移除图片生成的现行产品入口、运行时实现和模型配置分支，减少维护面与用户认知负担。

## 范围

### 做

- 移除图片生成页面、图片对话页面、图片生成 API 客户端与服务端实现。
- 移除图片端点 endpoint 注册、端点分类 UI/API 类型和模型选择分支。
- 移除消息图片数据的运行时读写和图片渲染代码。
- 移除相关测试、样式、Electron manifest 生成结果和当前架构文档中的图片生成描述。

### 不做

- 不修改历史迁移文件和历史变更文档；`image_data`、`category` 等历史数据库列保留，保证已有数据库可继续启动。
- 不删除用户数据库中的历史记录，不做不可逆数据清理。
- 不改变文本聊天、Wiki、Agent、Memory、MCP 和图谱功能。

## 验收标准

- AC-001：当前前端路由、导航、设置页和 API 导出中不存在图片生成入口或调用。
- AC-002：当前服务端不注册图片生成 endpoint，不提供图片生成路由或服务实现。
- AC-003：当前端点配置只支持文本模型；现有文本聊天端点的创建、更新、激活和连接测试行为保持不变。
- AC-004：消息仓储、API 类型和消息列表不再读写或渲染 `image_data`。
- AC-005：代码搜索不再发现图片生成运行时符号、路径、组件和样式；历史迁移/历史文档中的保留记录可作为已知例外。
- AC-006：server/client/agent-eval 测试、类型检查、构建和 `git diff --check` 通过。
