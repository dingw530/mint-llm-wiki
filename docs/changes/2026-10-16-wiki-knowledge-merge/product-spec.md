## 背景与目标

Mint 当前在 Wiki 摄入时使用标题相似度去重。标题达到阈值后，新页面会被移除，而不是把新资料合并到已有页面。另有同路径 LLM 合并逻辑，但它不能处理标题不同、实际指向同一知识对象的页面。

本变更让新资料能映射到已有知识页，并把新内容合并到该页。身份判断提供两种实现：Jev 开启且可用时优先使用 Jev；Jev 未开启或调用不可用时，使用当前配置的 LLM。无论哪个判断器失败，系统都保留新资料内容，不静默丢弃页面。

## 用户与场景

- 用户向本地 Wiki 导入一份新资料，其中的知识对象已存在于 Wiki。
- 新资料使用已有对象的别名、译名或略有差异的名称。
- 用户关闭 Jev，或 Jev API 不可用；摄入仍通过现有 LLM 完成身份判断。
- 两种判断都不确定时，用户需要看到独立的新页面，而不是错误合并或内容丢失。

## 用户故事

- **US-001**：作为 Wiki 用户，我希望新资料更新已有知识页，避免同一知识被拆成多个只因名称不同的页面。
- **US-002**：作为 Jev 用户，我希望系统优先使用已启用的 Jev 判断身份，并在 Jev 不可用时继续使用已有 LLM。
- **US-003**：作为知识维护者，我希望不确定的匹配保留为新页面，避免错误合并破坏既有知识。
- **US-004**：作为 Wiki 用户，我希望主动把已存在的重复页面合并到规范页，并保留被合并页面的原始修订内容。

## 范围

### 本次做

- 为 Wiki 身份判断增加 Jev 独立开关，默认关闭；关闭或不可用时使用现有 AI Provider 的 LLM 判断。
- 通过标题与已有 aliases 为新页面查找有限候选；精确标题/别名匹配继续走确定性路径。
- 对新页面标题和每个 alias 分别召回最多 5 个相关候选，按规范路径去重后合并候选集。
- 将新页面映射到唯一的规范已有路径，并在写入前合并页面内容、摘要与标签。
- 只有高置信“同一知识对象”才自动合并；不同或不确定时保留新页面。
- 保留现有原始资料、manifest、Claim 生命周期、搜索索引和图谱提交流程。
- 新增 `wiki_merge` Agent 工具，对一个既有源页复用候选召回和 Jev→LLM 判定，合并到唯一规范目标；归档源页快照后移除活动源页。
- 合并成功后同步链接、manifest、生命周期 Claims、图谱和搜索索引；工具调用要求审批。

### 本次不做

- 新增数据库表或迁移；改变 Markdown 文件作为 Wiki 正文的存储方式。
- 自动删除或重写旧页面；跨 Wiki、跨知识库身份合并。
- 依据内容向量相似度全库扫描；候选集仅使用现有标题相似度和显式 aliases。
- 自动裁决时间冲突；本期由合并提示保留旧信息，并要求新资料直接支持新增或修订内容。
- Jev 与 LLM 都不可用时强行合并或丢弃新页面。
- 提供绕过身份判定的任意目标路径合并；批量合并多个源页；删除或改写原始 Source 文件。

## 业务规则

- **BR-001**：标题相似度只用于候选召回，不可单独作为删除新页面或合并页面的依据。
- **BR-002**：页标题与候选页标题/别名精确匹配时，可确定性映射到候选页，不调用 Jev 或 LLM。
- **BR-003**：存在非精确候选且 Jev Wiki 身份开关开启时，先调用 Jev。
- **BR-004**：Jev 关闭、未配置、请求失败或响应无效时，调用现有 LLM 身份判断；有效但不确定的 Jev 结果不触发 LLM 重判。
- **BR-005**：Jev 仅在“同一对象”档位且 confidence ≥ 0.90、且该候选为唯一匹配时，允许映射到已有页。
- **BR-006**：LLM 只能选择当前候选列表中的路径，或返回 `new_page` / `uncertain`；输出无效、路径越界或身份不确定时保留新页面。
- **BR-007**：映射到已有页后，页面保留原有标题与路径；合并正文时保留旧有实质信息，并只加入新来源支持的内容；tags 与 aliases 去重并集并写回 frontmatter。
- **BR-008**：同一批次多个新页面映射到同一已有页时，系统先合并成一个目标页更新，不能以多次写入互相覆盖。
- **BR-009**：身份判断或页面合并异常不得导致新来源/新页面内容静默丢失；失败按现有摄入错误与回滚规则处理。
- **BR-010**：Jev 开关默认关闭，保存/读取沿用现有设置接口与加密设置存储，不返回 API Key 明文。
- **BR-011**：身份判定结果为不同或不确定、或现有文件名冲突时，写入路径必须不覆盖其他规范页。
- **BR-012**：对新页面标题及每个 alias 独立按相似度召回最多 5 个候选；仅保留相似度 ≥ 0.75 的结果，按文件路径去重后合并；不同新页面的候选集不得互相串用。
- **BR-013**：`wiki_merge` 仅接受 Wiki 根目录中已存在的 `pages/**/*.md` 源页路径；候选集排除源页自身。
- **BR-014**：既有页面合并复用 BR-002 至 BR-006 的精确匹配、Jev 优先、LLM 降级、置信度及候选路径约束；没有唯一可信目标时不产生副作用。
- **BR-015**：成功合并时目标页路径与标题保持不变，源页正文和元数据进入目标；页面 LLM 合并异常时确定性追加并保留双方正文。
- **BR-016**：在删除源页活动文件前，将其完整 Markdown 原文归档到 `sources/` 并写入 manifest；生命周期记录保留源页历史版本，并创建目标页新版本。
- **BR-017**：成功提交将指向源页的 Wiki 链接、manifest 页面路径、图谱边及搜索索引更新到规范目标。
- **BR-018**：`wiki_merge` 是高风险文件写操作，始终要求用户审批且禁止自动重试；未批准时不写入、不删除。
- **BR-019**：任一匹配前检查或提交步骤失败时保留活动源页；归档快照和目标更新失败可回滚，不静默丢失内容。

## 验收标准

- **AC-001（高）**：标题或显式别名精确匹配时，新内容写入已有页面路径，保留已有标题；不再生成重复页面。
- **AC-002（高）**：非精确候选且 Jev 开启时，Jev 高置信判定同一对象会映射到已有页；判为不同或低置信时保留独立页面。
- **AC-003（高）**：关闭 Jev 时，LLM 被调用并返回统一身份结果；候选路径校验失败时不合并且不丢失新页面。
- **AC-004（高）**：Jev 未配置、超时、网络失败或响应无效时，LLM 被调用一次；两者都失败时不自动合并，摄入结果可诊断。
- **AC-005（高）**：标题相似但身份不同的页面保留为独立页面；仅标题相似不能删除新内容或覆盖已有路径。
- **AC-006（高）**：多个新页面映射到同一旧页时一次性合并全部新增内容；最终页同时包含旧内容和所有新增证据支持的内容。
- **AC-007（高）**：合并后的 Wiki 页面、manifest、Claim 生命周期、搜索索引和知识图谱仍使用最终规范路径/标题，且原始 Source 归档保持不变。
- **AC-008（中）**：设置 → 实验性功能提供独立的 Jev Wiki 身份判断开关；默认关闭，启用/关闭状态可保存并回显。设置往返有 integration 与 browser 证据。
- **AC-009（中）**：每个新页面的标题及各 alias 都独立召回最多 5 个高相关页面；重叠候选只出现一次，任一 alias 的 Top‑5 候选都不会因其他 query 排名更高而被全局截断；候选仍只进入既有 Jev/LLM 身份判断，不直接触发合并。
- **AC-010（高）**：Agent 可发现并调用 `wiki_merge({sourcePath})`；路径越界、非 pages Markdown 或源页不存在时拒绝执行且 Wiki 无变化。
- **AC-011（高）**：工具排除源页自身，按每个标题/alias 召回候选；无候选、different、uncertain、无效路径或 provider 不可用时源页和目标页不变。
- **AC-012（高）**：Jev 开启时执行 Jev→LLM 既有优先级；只在确定性唯一匹配或唯一高置信 Jev match / 合法 LLM candidate match 时选定目标。
- **AC-013（高）**：成功后目标页规范路径/title 不变；目标正文、源页正文及 tags/aliases 均保留，旧内容不丢失；不安全 LLM 输出退回确定性追加。
- **AC-014（高）**：成功删除源页活动文件前保存完整源页快照；生命周期保留源页 superseded 版本、目标页产生新版本且迁入 Claims 可在目标页找到。
- **AC-015（高）**：成功后其他页面链接与 manifest pageFiles 不再指向活动源路径，图谱边重定向到目标节点，FTS/可选向量搜索只索引规范目标页。
- **AC-016（高）**：目标写入、链接/manifest/lifecycle/graph 更新或重建索引步骤失败时，源页快照仍可恢复，且不把源页活动文件提前删除。
- **AC-017（高）**：工具 metadata 声明 always approval 和 retrySafety=never；未批准的调用不产生文件、SQLite、图谱或索引副作用。

## 风险与依赖

- Jev 中文身份判断质量未经 Mint 数据验证；默认关闭，自动合并阈值保守，并以真实 Mint 页面候选集做离线样本评估。
- Wiki 编译器影响所有上传与 Chat 摄入入口；实现保持 `compileSource` 返回结构不变，并覆盖两种调用路径。
- LLM 输出会被视为不可信数据，所有目标路径必须来自候选集合，禁止模型生成任意文件路径。
- GitNexus 对 `deduplicatePages` 与 `finalizeCompiledPages` 报告 CRITICAL；结果包含明显非 Wiki 调用链噪声。实现前须以源码调用点、定向集成测试和回归证据补充影响审查，不能以索引风险轴抵消 CRITICAL。
