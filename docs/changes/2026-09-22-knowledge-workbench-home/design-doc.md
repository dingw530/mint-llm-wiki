# 设计文档：知识工作台首页收敛

## 设计决策

1. 以现有 `WikiPage`、`WikiSidebar` 和 `WikiPanel` 为边界做局部改造，不引入新的后端接口。
2. 将 `/wiki` 作为根路由默认页面，保留显式 `/chat` 和 `/agents` 路由。
3. `SidebarHeader` 只调整导航渲染顺序，不改变各模块的路由和图标语义。
4. 将 Wiki 无选中文档状态从装饰性欢迎页改为紧凑工作台：标题、知识库提问、向量索引状态和下一步动作。
5. 复用现有 `WikiVectorHealthCard` 的真实索引健康数据，避免用静态数字伪造知识库状态。
6. 文件树只在根层展示用户工作的 `sources`、`pages` 和索引文件；内部 manifest、schema、摄入临时目录和编辑器配置不作为默认导航内容。

## 影响边界

| 区域                   | 处理                                         |
| ---------------------- | -------------------------------------------- |
| Router                 | 根路由重定向到 `/wiki`                       |
| Shared navigation      | 调整知识库、对话、助手顺序                   |
| WikiPanel              | 简化无文件选中状态的主内容                   |
| Wiki CSS               | 删除默认页大面积装饰布局，增加紧凑工作台布局 |
| Wiki existing features | 文件树、标签、上传、图谱、热度、摄入任务保持 |
| Server/API             | 不修改                                       |
