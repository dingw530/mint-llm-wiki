# 产品规格：知识工作台首页收敛

## 变更状态

状态：已完成
完成日期：2026-09-22

## 背景与目标

Mint 定位为个人知识工作台。本次将当前知识库空状态页收敛为简洁的知识工作台首页，并将主模块顺序统一为“知识库 → 对话 → 助手”，让用户进入产品后优先看到资料、索引状态和基于知识库提问入口。

## 范围

### 做

- 默认路由进入知识库。
- 左侧模块顺序调整为知识库、对话、助手。
- 保留知识库现有文件树、文档/图谱/热度切换、上传和摄入任务入口。
- 简化知识库无选中文档时的主内容，突出标题、知识库提问和索引状态。
- 将主标题和提问入口居中，降低首屏视觉分散。
- 首页内容整体向下布局，使提问输入框接近主内容区域垂直中心。
- 文件树默认只展示 `sources`、`pages` 和索引文件，隐藏内部配置与摄入临时目录。
- 将图谱和热度保留在现有二级标签，不放在默认首页主视觉中。

### 不做

- 不改变聊天、助手、Wiki 检索或摄入 API 契约。
- 不删除图谱、热度、文档阅读和摄入任务功能。
- 不新增虚构的知识库数据或新的后端接口。

## 验收标准

### AC-001：知识库成为默认入口

- 风险：中
- 不变量：访问根路由后最终 URL 为 `/wiki`，且知识库页面可见。
- 最低证据：browser
- 探针：浏览器访问根路由并断言知识库导航和页面标题。

### AC-002：模块顺序正确

- 风险：低
- 不变量：侧栏模块可见顺序严格为“知识库、对话、助手”；三个链接仍分别指向 `/wiki`、`/chat`、`/agents`。
- 最低证据：browser
- 探针：读取侧栏导航文本和链接顺序，逐一点击验证路由。

### AC-003：知识库首页突出核心工作流

- 风险：中
- 不变量：无选中文档时同时可见“知识库”“基于知识库提问”“知识状态”，且不存在默认首页的大型热度分析和排名模块。
- 最低证据：browser
- 探针：进入 `/wiki`，断言标题、输入框、状态区和默认页不出现“知识热度”“页面排名”。

### AC-004：现有知识库能力保持可达

- 风险：中
- 不变量：文档/图谱/热度标签和摄入任务入口仍可见；文件树根层只展示 `sources`、`pages` 和索引文件。
- 最低证据：browser
- 探针：断言标签和文件树控件存在，断言内部配置/临时目录不显示。

### AC-005：实现质量回归通过

- 风险：中
- 不变量：客户端测试、类型检查、构建、格式检查和 Harness inspect/verify 无业务失败。
- 最低证据：integration
- 探针：运行项目测试、typecheck、build、Prettier、diff check 和 Harness 命令。
